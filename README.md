# SkyAgent

Research homepage for **SkyAgent: Revisable Target Memory for Continuous Aerial Search**.

## Local preview

No build or dependencies required. From this directory run:

```sh
python -m http.server 8000
```

Open http://localhost:8000. The paper is included at `assets/SkyAgent.pdf`.

## GitHub Pages

In the repository's **Settings → Pages → Build and deployment**, select **GitHub Actions** as the source. Push to `main` or run **Deploy paper homepage** from the Actions tab. The expected project URL is https://ykb19.github.io/SkyAgent/ (available after a successful deployment).

## Editing

- `index.html`: authors, affiliations, research text, and results.
- `style.css`: responsive visual design.
- `script.js`: copy-project-link interaction.
- `assets/`: the original paper and figures cropped from it (Figures 1, 2, and 4).

Results are transcribed from Tables 1 and 3 of the supplied manuscript. The page does not imply an accepted publication venue or a released implementation. No external fonts, analytics, or frontend dependencies are used.
